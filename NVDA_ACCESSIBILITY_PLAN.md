## 1. Архитектурный подход и интеграция с NVDA

### 1.1. Прямой нативный мост NVDA Controller Client API
Для взаимодействия с NVDA используется официальная 64-битная библиотека **`nvdaControllerClient.dll`** (NVDA Controller Client API 3.0, совместимая с NVDA 2026.3 и более ранними версиями).
Библиотека взаимодействует со службой NVDA через локальный Windows RPC (`ncalrpc:[NvdaCtlr...]`).

**Компоненты нативного моста (`native/x64/`):**
1. **`nvdaControllerClient.dll`** (официальная библиотека NV Access) и заголовочный файл `nvdaController.h`.
2. **`nvda_bridge.exe`** — легковесный автономный C-процесс (скомпилированный `clang.exe` с `nvdaControllerClient.lib` без внешних зависимостей, размер ~25 КБ):
   - Запускается игрой автоматически в фоновом режиме при старте через `OS.execute_with_pipe`.
   - Обменивается с Godot быстрыми командами через стандартный ввод/вывод (stdin/stdout) в формате JSON-lines:
     - `{"cmd": "test"}` $\rightarrow$ проверяет активность NVDA (`nvdaController_testIfRunning()`). Возвращает `{"active": true/false}`.
     - `{"cmd": "speak", "text": "...", "interrupt": true/false}` $\rightarrow$ передает текст для чтения в NVDA (`nvdaController_speakText()`), при необходимости предварительно вызывая `nvdaController_cancelSpeech()`.
     - `{"cmd": "cancel"}` $\rightarrow$ сбрасывает текущую речь (`nvdaController_cancelSpeech()`).
     - `{"cmd": "braille", "text": "..."}` $\rightarrow$ выводит сообщение на дисплей Брайля (`nvdaController_brailleMessage()`).
   - При закрытии игры процесс моста гарантированно завершается автоматически.

### 1.2. Одноканальность и Fallback
- Если NVDA запущена $\rightarrow$ **100% речи идет исключительно через NVDA** (с выбранным пользователем голосом, скоростью и тембром). Встроенный TTS Godot полностью отключается, исключая любое эхо или наложение голосов.
- Если NVDA не запущена $\rightarrow$ работает автономный режим с опциональным встроенным синтезатором (`DisplayServer.tts_speak`) для зрячих или пользователей без скринридера.

## 2. Полная клавиатурная навигация и управление фокусом

### 2.1. Глобальные правила навигации:
- **`Tab`** и **`Shift + Tab`** — последовательный переход между всеми интерактивными элементами экрана в логическом порядке.
- **`Enter`** и **`Space`** — активация кнопок, переключение флажков (CheckButton/CheckBox).
- **Стрелки `Left / Right` и `Up / Down`** — изменение значений ползунков (громкость), выбор режима в карточках, навигация по выпадающим спискам.
- **`Escape`** — закрытие модальных окон (Настройки, Сохранить/Загрузить, Титры) с возвратом фокуса на элемент, из которого окно было вызвано, либо в строку ввода команд игры.

### 2.2. Экраны и сценарии:
1. **Экран выбора режимов (`ModeSelectScreen`)**:
   - При открытии: NVDA объявляет: *"Выбор режима игры. Выберите один из трех режимов оформления и звучания."*
   - Фокус: кнопки смены языка (`🇷🇺 Русский`, `🇬🇧 English`), затем карточки режимов (`Современный`, `Ретро VGA`, `Классический ZX`).
   - Для каждой карточки сообщается: название режима, состояние (выбран / доступен), описание графики, звука и шрифта.
2. **Главное меню (`TitleScreen`)**:
   - При открытии: *"Главное меню. Доступны: Начать игру, Загрузить игру, Настройки, Сменить режим, Об игре, Поставить звезду на GitHub, Выход."*
   - Логический порядок Tab: `Начать игру` $\rightarrow$ `Загрузить игру` $\rightarrow$ `Настройки` $\rightarrow$ `Сменить режим` $\rightarrow$ `Об игре` $\rightarrow$ `Поставить звезду на GitHub` $\rightarrow$ `Выход`.
3. **Окно настроек (`SettingsPanel`)**:
   - Логический порядок Tab: `Полноэкранный режим (флажок)` $\rightarrow$ `Ползунок громкости музыки` $\rightarrow$ `Выбор языка (выпадающий список)` $\rightarrow$ `Выход в главное меню` (если открыто из игры) $\rightarrow$ `Кнопка Назад`.
   - Ползунок громкости: при изменении стрелками объявляет: *"Громкость музыки: 70 процентов"*. Предусмотрен дебаунс (ограничение частоты), чтобы не спамить синтезатор при быстром перемещении.
4. **Окно сохранений и загрузок (`SaveLoadScreen`)**:
   - Логический порядок: переключатель страниц (если активен) $\rightarrow$ слоты с 1 по 6 $\rightarrow$ кнопка «Закрыть».
   - Для каждого слота при фокусе объявляется:
     - Пустой слот: *"Слот 1: Пусто. Нажмите Enter для сохранения."*
     - Занятый слот: *"Слот 1: Уютная прихожая. Режим: Ретро VGA. Здоровье: 100. Ходов: 15. Сохранено: 27 октября 15:30. Нажмите Enter для сохранения, стрелку вправо для удаления."*
   - Клавиша `Delete` или фокус на корзину: открывает модальный диалог подтверждения с кнопками `Да, удалить` и `Отмена`.
5. **Экран «Об игре» (`CreditsScreen`)**:
   - Текст титров разбит на логические абзацы; клавишами `Up` / `Down` незрячий игрок может последовательно читать каждую строку или абзац истории создания игры.
   - Клавиша `Escape` или кнопка `Назад` закрывает титры и восстанавливает фокус в главном меню.

## 3. Игровой процесс и чтение мира через NVDA

### 3.1. Строка ввода команд (`InputLine`):
- Строка ввода всегда удерживает активный фокус во время игрового процесса.
- NVDA самостоятельно зачитывает вводимые буквы, слова, удаление символов (`Backspace`) и навигацию курсора (`Left / Right`). Игра не дублирует посимвольный ввод!
- При нажатии `Enter`:
  1. Команда отправляется в парсер.
  2. NVDA получает объединенный и очищенный от тегов результат хода (ответ игры, реакцию спутников, изменения вокруг).
  3. Поле ввода очищается, и фокус гарантированно остается в `InputLine` для непрерывного набора следующей команды.

### 3.2. Горячие клавиши для быстрого чтения информации (In-Game Shortcuts):
Специальные клавиши, не конфликтующие с NVDA:
- **`F1`** или **`H`** — озвучивание краткой справки по доступности и горячим клавишам.
- **`F2`** — повтор полного описания текущей локации (название, описание окружения).
- **`F3`** или **`F4`** — повтор последнего игрового сообщения / ответа парсера.
- **`F5`** — озвучивание только доступных выходов из локации (например: *"Выходы: на восток (дверь, закрыта), на запад"*).
- **`F6`** — озвучивание видимых предметов и присутствующих персонажей (например: *"Здесь находятся: Торин, Гэндальф. На полу лежит: карта, эльфийский меч"*).
- **`F7`** — озвучивание статуса хоббита (здоровье, сила, время суток, текущий режим графики).
- **`Page Up` / `Page Down`** — полистрочное чтение истории журнала событий назад и вперед.
- **`Escape`** — открытие внутриигрового меню настроек / паузы.

### 3.3. Приглушение звука (Audio Ducking):
- Во время воспроизведения речи через NVDA фоновая музыка плавно приглушается (до 10–15% от текущей громкости) и плавно восстанавливается после завершения фразы. Это гарантирует максимальную разборчивость речи.

## 4. Тестирование без установки NVDA в систему пользователя

### 4.1. Безопасность системы пользователя:
- У пользователя скачан установщик `nvda_2026.3.exe`.
- **Устанавливать NVDA в Windows НЕ требуется!**
- Установщик NVDA поддерживает создание автономной переносной копии (Portable copy) либо временный запуск без установки:
  1. Мы распакуем переносную версию в папку `g:\Coding\The Hobbit Remake\Hobbit_1982_Remake_NVDA\nvda_portable\`.
  2. Портативная NVDA запускается из папки и работает изолированно: не вносит изменений в реестр, не ставит драйверов, не создает служб.
  3. Для завершения работы достаточно нажать `Insert + Q` (или `CapsLock + Q`) $\rightarrow$ `Enter`.
  4. После окончания тестов папка `nvda_portable\` просто удаляется, и система возвращается в абсолютно исходное состояние!

## 5. Поэтапный план реализации

| Этап | Задача | Результат |
| :--- | :--- | :--- |
| **Этап 1** | **Компиляция нативного моста `nvda_bridge.exe`** | Создан `native/x64/nvda_bridge.exe`, линкующий `nvdaControllerClient.lib`. Проверена работа `testIfRunning`, `speakText`, `cancelSpeech`, `brailleMessage`. |
| **Этап 2** | **Создание менеджера доступности `scripts/nvda_manager.gd`** | Автономный синглтон/класс: запуск моста, автоматическое обнаружение запущенной NVDA, очистка BBCode, приглушение музыки (audio ducking), маршрутизация речи. |
| **Этап 3** | **Клавиатурная навигация и фокус во всех меню** | Настройка порядка Tab/Shift-Tab, стрелок, Space/Enter/Escape, объявление названий экранов, типов и состояний контролов в `ModeSelectScreen`, `TitleScreen`, `SettingsPanel`, `SaveLoadScreen`, `CreditsScreen`. |
| **Этап 4** | **Игровой процесс, журнал и горячие клавиши** | Непрерывный фокус `InputLine`, чтение результатов хода, горячие клавиши `F1`–`F7`, `PageUp`/`PageDown`. |

| **Этап 6** | **Сборка Windows-релиза и публикация на GitHub** | Экспорт `The Hobbit.exe` с включенными `nvda_bridge.exe` и `nvdaControllerClient.dll`, создание zip-архива, пуш в репозиторий `mrtek/Hobbit_1982_Remake_NVDA` и публикация первого релиза на GitHub. |

## 6. Критерии готовности (Приемка по разделу 8 ТЗ)

1. ✅ Запуск игры с запущенной NVDA — игра автоматически подхватывает скринридер без лишних действий со стороны игрока.
2. ✅ Меню выбора режима, настройки, экраны сохранений и титров проходятся только с клавиатуры без использования мыши.
3. ✅ Все элементы объявляют имя, тип и состояние («кнопка», «отмечено/не отмечено», «громкость 50%»).
4. ✅ В поле ввода команд NVDA штатно читает вводимые символы и перемещение курсора; результат хода произносится полностью, фокус остается в поле ввода.
5. ✅ Горячие клавиши `F2`–`F7` позволяют в любой момент перечитать локацию, выходы, инвентарь или последнее сообщение.
6. ✅ Нет дублирования речи (встроенный голос Godot молчит, если говорит NVDA).
7. ✅ Отсутствие NVDA не приводит к ошибкам: игра штатно работает как обычное графическое приложение.
